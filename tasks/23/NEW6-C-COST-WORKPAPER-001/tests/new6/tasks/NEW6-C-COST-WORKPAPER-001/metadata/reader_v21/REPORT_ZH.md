## 修复的读取问题

原 Judge 无法解释 `Original Estimate / Current Review / Movement`、包价格表、费率表及竖排成本变动桥。新增适配器依据实际表头、业务标签、段落和表内包含关系区分原额、当前额、变化量及来源摘录，不按参考金额或固定坐标选答案。

同范围替换允许由候选自身明确列出的旧、新供暖包价格和 M&E 总额变动共同证明，未写 `replace` 一词不会失分。来源表中引用的 12% 是审阅往来的原始事实，会议修改工作费率后该来源摘录可以保持 12%。工作表的当前费率则必须随明确的可编辑输入变化。

竖排桥中“供暖变化”和“费用影响”按增量读取，不当成全部当前成本。成本限额、核对成本限额和直接计算三个展示都保留。重复的原额、变化量或当前限额角色，以及无法唯一定位的编辑控件，均明确待判；未知业务表和未解决的合法公式/引擎错误也保持待判。
