# A2 requirements basis — natural-business-v2

The official downloaded LTGM workbook is v4.42 and opens with Peru selected. This task uses the separately recorded Zambia configuration in `configuration_manifest.json`. Those two states are distinct. `source_oracle_verification.json` checks the configured source against the raw-country-data Decimal Oracle. The source model and Oracle remain unchanged by this prompt revision.

The current deterministic R006 text check verifies the illustrative scope markers; it is not a general semantic reviewer of every prose claim. Comprehensive agentic interpretation review and externally applicable negative-item acceptance remain separately unverified; no claim of complete external acceptance is made.

Unsupported requirements: exact source XML, exact formulas, fixed output coordinates, extra native Excel features, poverty results, short-run demand forecasts, additional dynamic input types, hidden hurdles, score caps, or a particular natural-failure rate. These are not scored. If a valid source/layout/unit interpretation is outside the bounded adapter, the outcome is pending adjudication rather than a score of zero.

The shorter prompt removes repeated parameters and method hints. The complete reference, independent Oracle, factual scope, three profile weights, and sole unrounded >= 0.70 pass rule are unchanged. It is a new prompt condition, not a new numerical task. No paid sample exists under the earlier condition.
