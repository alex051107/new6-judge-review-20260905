没有来源支持、不得新增扣分的要求：固定工作表名、固定地址、逐单元格重复引用、XML/样式完全一致、唯一查价公式、未请求的图、额外邮政产品或未声明的复杂包裹场景。本轮不增加这些要求。

实现边界：v2.1 支持服务标题、重量标签与 zone 表头共同确定的横向价表，包括移动重量列和倒序 zone 列；参考 192 个价格事实与身份在宽表中保持等价，单价错误和重复身份仍被保留供评分。缺乏可绑定服务/单位的实质表格继续待判。非当前别名的字段仍可能需要语义绑定；不把 parser 的列约定升级成题面要求。

新旧义务保持审读结论：规定的业务对象、范围、资格、交付、可编辑输入、来源可回查及 tie 规则保留。删掉了页码导航、upper-bound 解题提醒、16 oz 换算教学，以及 instruction 已包含的逐项报价和求和重复指令。正确 reference 的已验证业务含义仍满足新可见请求；这是一次文义和证据对应审读，不是新的 Agent 可解性实验、独立双人验收或难度证明。

## 用户授权的下游使用计分修订

主方案权重依次为 35/10/10/35/5/5。原材料还原与身份/单位占45%，实际会变化的报价和总额传播占35%。R004 的11个事实由独立Oracle先确定，只有预期非零的美元变化或应切换的服务选项计入；预期不变结果、保留的原价表和未受影响请求共同比对并计入R005（总分母26）。不按候选答案选择分母。基线准确性、变化响应、保留义务分别计分，正确变化量不因恒定数值偏移重复失去信用。

10项针对性校准复用了既有原生重算快照；新增的服务价表归属互换反例只做了一次完整Judge。参考、等价布局/公式均为1，纯静态报价的R004=0、主分数0.65；整块服务归属错误为0.56798082869511440940012368586。以上是评分区分能力的校准，不是自然Agent失败率。共享表级来源与全局日期有独立通过回执，未知实质引用待判，明确缺引用只损对应事实。
