# Online Retail source

Daqing Chen (2015), Online Retail, UCI Machine Learning Repository, dataset 352. DOI: https://doi.org/10.24432/C5BW33. Source: https://archive.ics.uci.edu/dataset/352/online+retail. CC BY 4.0: https://creativecommons.org/licenses/by/4.0/.

The original data covers transactions of a UK-based non-store retailer. InvoiceNo is the transaction document, StockCode the item identifier, Description the item name, Quantity the line quantity, InvoiceDate the supplied timestamp, UnitPrice the sterling unit price, CustomerID the customer identifier and Country the customer country.

The extract contains all original records dated 30 September through 1 November 2011. source_row_id records the original worksheet and physical row number. Timestamps use ISO notation without timezone conversion; missing values remain blank. The review policy is project-authored and is not presented as the retailer's own accounting procedure.
