# Review scope
Use English lower-tier and unitary/local authorities in the supplied releases, identified by geography codes beginning E06, E07, E08 or E09. Use each indicator's source population definition and observation period. Calculate changes from the published rates displayed to one decimal place, in percentage points.

Continued deterioration means unemployment rose and employment fell in each of the two consecutive comparisons. Rank qualifying authorities by the cumulative unemployment-rate increase from the first to the last period, largest first, then geography code ascending for ties. Select up to five; if fewer qualify, include all. Explain why authorities with insufficient comparable information cannot be assessed; do not impute missing values.

The previous workbook is a project-reconstructed briefing using the first two supplied periods, with a correctly documented single-comparison shortlist. Preserve that analysis for review, in clearly identified historical sheets or in the retained previous workbook with a clear reference from the update. A correct static workbook is acceptable.

The January 2023 dataset's supplied file is its official corrected replacement, internally published in February 2023. Its correction note and observation-period labels remain in the original workbook. The other two releases are January 2024 and January 2025. This is a benchmark-authored update exercise using public statistics.
