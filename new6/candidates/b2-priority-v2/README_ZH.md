# ONS 劳动力比较：动态复核候选 v2

这个独立版本保留两期原始 ONS 表及原来的统计比较，增加可调整的复核工作簿。它不改变正在执行的 NEW6 144 次冻结批次，也不把旧答卷按新义务重新扣分。

使用者修改失业上升门槛、就业下降门槛或名额后，每个地区的资格、选择、当前清单及人数应自动更新。两个门槛可以独立修改，缺失值不能当零，符合条件不代表有名额；排名按失业增幅、就业降幅和地区代码依次决定。三种固定情景与原始统计表保持不变。门槛是题目公开的工作政策，不是统计显著性的判据。

本版主方案给原统计交付 30 分，固定复核筛选与清单 20 分，实际动态使用 50 分。三套配重共享同一事实向量，仅未舍入总分 >= 0.70 通过。动态分中，初始当前结果占 10%，四次真实输入变化后应变化的事实占 80%，应保持不变的结果占 10%。没有额外 hurdle、封顶或重复罚款。

参考的固定情景用 JavaScript 整数十分位独立构造，Oracle 从原表用 Decimal 重算并与原始 OOXML 核对。动态参考使用 Excel 原生 COUNTIFS、INDEX/MATCH 等公式；Judge 不解释公式，使用独立副本和 LibreOffice 实际重算。参考在本机和固定 Linux Judge 镜像均得 1.0。构造正反例只用于校准，不代表自然失败率或正式难度。

复查入口：tasks/NEW6-B-LABOUR-BRIEF-001/tests/calibrate_dynamic.py。使用含 openpyxl/lxml 的 Python 和 LibreOffice。完整 Docker 单题验证可将本目录挂载到 /work，使用 new6-judge:20260905；同一镜像定义见主仓库 new6/repro/Dockerfile。具体回执见 validation/linux_reference.json 和逐题 metadata/dynamic_calibration/。真实试跑另记在 new6/campaigns/b2-dynamic-pilot/runtime/，不属于原144次。

本轮校验预算：一次原表独立核对；一次12例双向校准；新增重复/未绑定表示风险补两例；一次固定 Linux 参考验证。每例断言应失分项和应保持项。源文件没有变化，不重复下载或做旧题全量重评。

最新原件复评：读取器 v2.1 修复后，真实首答为76.72分；原生参考与等价公式均100，静态实时快照60。详细问题、回执与复算入口见 [实际试跑复核](ACTUAL_PILOT_REVIEW_ZH.md)。这是独立加难版的一次样本，不与原版92分答卷当成同样本因果对照。
