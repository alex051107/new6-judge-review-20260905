# 本次发布验证预算

- 包装批次：1 次结构/JSON/TOML/输入隔离检查；当前会话自检；导入文件身份清单 1 次。以六题输入均存在、原判分定义未被 Schema 导出改变为停止点。
- 离线批次：1 个六题参考五次重复 runner、1 个18例随包校准 runner、1 个42份已评分原件 replay runner；当前会话自检。分别验证稳定性、合理实现/错误区分和真实分数复现。
- 新风险：重新构建的镜像获得新 image ID，追加1个六题参考 runner，检验新构建环境；C2 原件出现未绑定控件却出零分，追加1个独立单元格/单位核对，确认误判。诊断脚本的字段名错误修正后仅重跑自身，不改 Judge。
- 自有答卷入口：追加1次 score 子命令，用B2参考作为调用方答卷验证参数、路径和输出回执，得分1.0；不计新Agent样本。
- 发布批次：1 次文本敏感信息与链接/统计检查；1 次最终文件身份清单；远端提交与文件回读。无额外 Agent 调用，无付费 Judge。

实际结果由 results/VALIDATION.md 汇总。未变更的开发全套测试、旧版本校准和历史 Agent 运行不重复。已知业务/Judge缺陷列入审查，不在本轮改分。

用户后续明确要求并行处理，实际另有三个代理分别完成包装、统计和低分审查；没有代理启动新的做题运行。
