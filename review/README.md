## 一题怎样审

1. 先读题面与业务说明，写清使用者要交出什么，核对公开原始事实与项目重构请求是否分开。
2. 用有权限的私有包打开全部输入与参考工作簿，自己核对一组关键数值或业务关系。没有权限就记录“材料不足”，不要凭说明页签通过。
3. 按逐项评分标准查看参考、合理等价实现、业务错误和边界案例，再对照一份真实答卷及其详细回执。复跑入口默认只评分已有答卷。
4. 每个问题填写审查者、日期和证据位置，结论选“通过 / 需修改 / 材料不足”。有问题写明改什么；返修后填写版本和复核结果。
