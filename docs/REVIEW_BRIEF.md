# 六道专业Excel任务：审查说明

这六道题检查Agent能否把专业材料做成可核对、可继续使用的工作簿。它们覆盖专业计算、数据分析和文档规则三类工作。初步结果可以用于定位失分与审查题目，但目前尚无题目完成全部难度验收。

## 先看题目和材料

|轨道|要完成的工作|主要核验|
|---|---|---|
|A 专业计算|补全估值模型，计算投资路径对长期增长的影响|计算关系、年度时序、情景变化与完整结果|
|B 数据分析|核对零售月结，更新劳动力简报|完整对象、统计或交易口径、明细与结论一致|
|C 文档规则|更新工程成本，按资费计算寄件报价|有效版本、范围、限定条件、计价与适用的后续更新|

六题的请求由项目根据公开材料重构，具体业务背景、来源和交付见[业务说明](BUSINESS.md)。[每题审查入口](../review/README.md)直接提供题面、输入、参考与真实答卷下载。

## Judge怎样判分

先从原工作簿绑定对象、字段、期间和单位，再核对独立事实与业务关系，检查题目要求的完整性、更新和保护，最后按冻结条目汇总。数值、记录和明确业务规则采用确定性程序；评分时不调用在线LLM。B1已有视觉转录的使用范围和待补身份单独披露，见[评分方法](JUDGE.md)。

同一业务结果可能放在不同工作表中。只要对象和含义能够明确对应，合理布局应得到相同信用。确认缺交或算错的部分按对应条目失分；仍可能存在但读取器无法定位的部分留待核查，不直接记零。当前读取范围还有限，部分答案因此不能给出完整总分。

## 对布局差异，可以借鉴什么

[TabEval（EMNLP 2024）](https://aclanthology.org/2024.emnlp-main.1239/)先把表格拆成事实，再核对与参考事实的关系。它提醒我们：应先确认工作簿表达了什么，再判断正确性和覆盖程度。[GriTS](https://arxiv.org/abs/2203.12555)在二维表格中匹配结构、位置和内容，为部分正确保留信用；它的结构识别指标不能直接代替业务评分。

[Semantic Evaluation of PDF Table Extraction](https://arxiv.org/abs/2603.18652)把表格匹配与语义评分结合，用于处理不同解析输出。它采用LLM评判，研究对象是PDF表格提取；本项目借鉴的是先对齐信息、再评价内容的顺序，当前没有部署其LLM评分器。

对这六题，拟继续固定“业务对象、字段、期间、单位、原始位置”的对应关系，再让程序核验数值和业务规则。最需要组内确认的是：哪些字段必须由题面明确，哪些合法布局应由读取器兼容；无法唯一定位时，人工核查的位置映射需要留下哪些证据。公式更新、修改范围和原有正确内容的保护仍要在工作簿中实际验证。

## 请审查哪些内容

请选一题，对照题面、输入、参考和真实答卷，重点判断：

1. 材料是否足够，参考中的业务规则和结果是否正确。
2. 评分条目是否覆盖主要工作，是否给合理布局和等价实现相应信用。
3. 有争议的单元格到底是业务错误、明确缺失，还是读取器没读对。
4. 现有结果是否支持难度结论，哪些真实业务要求还值得增加。

在[人工审查表](../review/README.md)中填具体文件、单元格、意见和复核结果。当前状态为待人工审查。
