# Judge如何读取工作簿并计算分数

当前77份结果按各回执实际版本归集，版本和未固定提交见[来源说明](../results/current-effective-v1/SOURCE_NOTES.md)。本页固定环境的完整重评分入口对应34374快照，不能保证直接重现其他未固定实现的分数；公开分项事实可用于配重复算。

当前结果统一使用Judge提交 `34374f08f331e7184010c40b401f1630a49df394`。Judge先记录逐项业务事实，报告按[当前能力配重](../results/unified-scores-v3/weights.csv)计算总分。原配重、50%比较与当前配重共享同一事实向量；当前配重是在已有结果后选择的报告口径，不记为事前冻结的难度验收设计。

## 从文件到分数

```mermaid
flowchart LR
    A[读取候选工作簿] --> B[绑定对象、字段、期间和单位]
    B --> C[核对独立答案与业务关系]
    C --> D[检查适用更新、完整性和保护]
    D --> E[保存逐项事实与信用]
    E --> F[按记录的权重汇总总分]
```

读取器确定答案的位置和含义，Evaluator核对业务结果，计分器汇总已验证的信用。例如B1先确定九月和十月销售、贷项、发票与SKU，再核对净额变化能否由贡献桥及明细解释。A类和适用的C类还会修改原答卷隔离副本中的真实输入，经LibreOffice重算后核对输出变化。

做题系统是Codex CLI、Claude Code或Qwen Code，负责操作材料并交付工作簿。Judge负责读取和核验。人工审查者检查场景、参考答案、评分公平性及下游可用性。系统的模型身份与Judge的工具身份分别记录。

## 程序检查、视觉读数与人工复核

业务判分采用确定性程序，评分时未调用LLM Judge。Python、OOXML/openpyxl读取记录、公式、单元格与原生图表；固定LibreOffice环境处理适用的重算。数值、记录身份、计价规则和年度递推可与独立答案复算，因此逐项保存实际值、预期值与得失分依据。

所有权重最终由程序计分，评分阶段LLM API调用占比为0。B1的位图图表有一项辅助输入：按原图哈希读取已保存的视觉转录，再由程序核对标签和数值。这属于R005的图表半项，最多涉及总分约2.46%；原生图表直接读取结构。该记录的生成者或模型身份未完整标注，需要人工对照原图核查，不能把它说成程序独立提取了所有业务事实。

[逐项method与当前权重](../results/unified-scores-v3/METHODS.csv)列出所有判据、能力组和辅助读取范围。[原方法表](METHODS.csv)保留原rubric权重作交叉核对。人工审查另行记录，没有把尚未完成的人工判断折算成正式分数。

[实际JUDGE配置](../repro/JUDGE_CONFIG.json)与[环境示例](../.env.example)不含密钥。每份Evaluator超时600秒，原生预重算超时120秒，自动重试0；容器断网，1CPU、3GB内存。批量入口未设置整批总超时。模型ID、provider、协议和提示模板为空，因为本评分入口没有调用模型API；它们不被写成已配置并验证。

## 权重、部分信用与通过规则

第i项的业务信用fᵢ介于0和1之间，来自该项既有事实分母；总分为Σ(wᵢ×fᵢ)/100。重点关系组占60%，其余业务核验占40%，组内保持原有相对权重。[六题能力说明](../README.md#判分依据与业务配重)解释各组测量什么，[精确权重](../results/unified-scores-v3/weights.csv)保留计算精度。

A1的基准保护原占5%，所在组原合计65%，现分得40%×5÷65≈3.1%。这样的零碎百分比来自比例换算，不表示权重已被验证到小数点后的精度。小数显示可简化，计算与通过判断仍使用未舍入值。

局部正确保留该项信用，不新增格式处罚。保护义务通过现有正向判据计分；没有独立负项、独立hurdle或隐藏封顶。唯一通过规则是可评分状态下未舍入score≥0.70。外发Schema中的0.6是示例，当前采用已确认的0.70。

当前表的均分分母是有本版完整评分的答卷数。尚待解析、运行或收集待核的记录不补零；12条OUTPUT_MISSING记录保留并单列，当前表未将其加入均分。原未交付政策允许对已确认运行和收集正常、确实未交文件的试次记0，但须先有该项证据。均分采用哪一分母在[来源说明](../results/unified-scores-v3/SOURCE_NOTES.md)中显式记录。

## 合理实现与判断边界

A轨核对专业计算链、时序和情景变化；B轨核对完整对象、交易或统计口径及明细到结论的证据关系；C轨核对文档版本、范围、限定条件和计价规则。B1、B2接受正确静态分析。自动更新只用于题面明确要求后续修改的任务。

任务未指定位置时，布局变化不应造成业务失分；明确缺失、错值或错误引用才在对应判据失分。当前程序支持的布局范围仍有限，未识别与真实缺交分别记录。[读取风险复核](../results/unified-scores-v3/LOW_SCORE_NOTES.md)列出三个已有数字但仍有读取风险的案例，相关低分不用于证明能力不足。未知项不填零，也不删掉后重新放大其余得分。

[当前五次一致性统计](../results/unified-scores-v3/consistency.json)来自同一A1原件的五次实际评分：六项信用和总分样本标准差均为0，低于0.05。它覆盖这一原件的重复评分，不证明所有布局都能被正确读取。

参考、等价实现、业务错误及边界案例随题包与[校准入口](../repro/README.md#基线参考与校准)保留。原基线17/18校准、当前Judge修复校准与真实答卷评分按版本分别记录；旧版本校准不能替当前版本作证。人工变造案例不计作Agent自然样本。当前尚待人工审查，程序校准和重复性检查均不替代逐题难度验收。
