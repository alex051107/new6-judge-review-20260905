# 发给学长的进展说明

学长好，我把新6题和原15题的结果更新到飞书了。题面、输入、参考答案、真实答卷和评分环境也放到了公开GitHub，可以直接下载复核。

这6题主要看Agent能否把专业计算、数据分析和文档规则落实到Excel里。现在最需要讨论的是Judge：同一份正确答案换了表名或布局，程序有时就认不出来，甚至会误扣分。我们把这类情况和确实算错、漏交内容分开列了，也放了可直接核对的答卷。

想请大家帮忙看三点：最终交付应该固定哪些字段和格式，读不出来时怎样复核和计分；偏容易的题增加哪些真实要求更合适；基于业务规则和原文证据给Agent修复反馈，相比已有方法还有没有值得做的研究空间。报告里分别放了处理建议、A/B/C样例和对照实验的初步安排。
