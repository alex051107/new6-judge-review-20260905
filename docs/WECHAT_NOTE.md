# 发给学长的进展说明

学长好，接着前面那6道题再更新一下。我把原15题和新6题的现有结果都放到飞书了，GitHub里也整理了题目材料、参考答案、真实答卷，以及评分环境和复跑说明，方便大家一起看。

这次重新设计题目，还是围绕前面想测的能力：Agent能不能读懂专业材料，把计算关系、分析口径和文档规则做进Excel，交出一份别人能核对、能继续用的工作簿。涉及后续修改的题，还会看它能否把相关结果一起更新，并保留不该改的内容。

目前已经看到不同模型在这些要求上的表现差异，不过部分题的得分仍然很高，千问样本和部分判分也还没核齐，6题还没有全部达到最初的难度验收目标。现在比较卡的是Judge：同一个业务结果可能有不同的合理布局，脚本有时没读对。我们在逐份核对，把这类读取问题和实际算错、漏交分开，避免把Judge的问题算到Agent头上。

想先请大家帮忙看一下材料比较完整的题，尤其是对照参考答案和真实答卷，看看现在的判分是否合理、有没有测到我们原本关心的能力。对于布局不同但内容正确的答卷，输出要求应该约定到什么程度、脚本读不出来时该怎样复核，也想听听大家的经验。

这轮还没完全做到预期，但题目、答卷和评分已经有了可以具体讨论的基础。我把相关论文的做法，以及继续增加真实业务要求的几个例子也放进了报告。希望先根据大家的意见，把能交的题确认下来，再继续改进偏容易的题和Judge，逐步往后扩展。辛苦大家帮忙看看。
