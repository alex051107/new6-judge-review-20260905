# 发给学长的进展说明

学长好，我把原15题和新6题的结果、题目材料、参考答案和真实答卷整理好了，也补了公开的评分环境，大家可以下载复核。

这6题主要看Agent能否把专业计算、分析口径和文档规则落实到Excel里。部分题还是接近满分，说明有些业务要求还不够难。现在另一个问题是Judge：答卷换了合理的布局，读取器有时会认错，所以需要先分清哪些是业务错误，哪些是我们没读对。

这次想请大家重点帮忙看：你们通常把最终输出格式固定到什么程度？结果确实存在但脚本找不到时，能否人工确认位置后再复算？确认少交、算错和暂时读不出，分别应该怎样计分？报告里放了实际答卷和具体情况，方便一起判断。

加难方面，我参考了BlueFin等论文的建题做法，写了A/B/C各一组具体例子，想请大家看新增的业务判断是否值得测。也想讨论：给Agent同样的原文和规则后，再说明这次修订影响哪里、哪些内容要保留，能否帮助它修得更准、少改坏；与已有方法相比，这个问题还有没有研究价值。

千问样本和部分判分还没核齐，六题尚未全部完成难度验收。希望先审查材料和判分已经比较完整的题。同时确认150题应怎样计算独立问题、安排参考和人审，先试产一小批，再估工作量。
