## 三轨分别测什么

![三轨能力与核验证据](results/unified-scores-v3/abilities_logic.png)

A轨检验专业模型中的关系是否成立。A1把年度经营预测接到再投资、现金流和估值，A2把投资路径逐年传到资本和GDP。核验既看每期数值，也改变题目指定的输入，检查依赖结果是否正确更新、基准与无关部分是否保留。它测的是能继续工作的计算模型。

B轨检验分析是否覆盖完整对象，并在明细、汇总、图表和结论之间保持同一口径。B1核对销售、贷项、发票和SKU对两月净额的贡献；B2核对三期发布中的地区身份、连续恶化名单与名单变化解释。正确静态分析可以满足要求，关键在范围完整、口径一致和证据可追溯。

C轨检验源文规则是否被正确落实。C1需要分清有效报价、替换范围和未批准选项，再形成可调节的成本链；C2需要保留服务、重量上界与分区规则，正确计算寄件报价。字段抽取只是起点，限定条件还必须约束计算；适用任务还要在输入变化后给出正确更新。

三轨的共性是可核对、可交接。持续使用包括两种具体需求：沿已有明细和来源复核分析，以及修改明确允许编辑的输入后得到新结果。是否要求自动更新取决于任务，不能把所有重点能力都归为动态能力。

## 判分依据与业务配重

权重优先分配给直接决定工作簿能否完成上述用途的业务关系。A1、A2、C1、C2对允许修改的输入施加变化，观察已有计算关系是否仍然成立；B1核对月度变化能否由贡献桥和SKU证据解释；B2核对新发布如何改变名单与简报。把更多分值分配给这些检查，是为了区分一次性呈现结果与完成后续业务工作的能力。

![六题业务要求与计分分配](results/unified-scores-v3/weights60.png)

当前采用下表的能力分配。其余核验同样包含实质业务判断：经营预测、资本递推、完整交易、连续恶化筛选、有效报价和价格网格，都独立计分。它们共同检查当前结果是否正确、范围是否完整、依据是否可靠。两组内部沿用原项比例，局部正确保留相应信用。

| 任务 | 后续使用与分析关系（60%） | 当前结果、规则与交付核验（40%） |
|---|---|---|
| A1 | 假设变化后的预测与估值 60% | 来源/单位 6.2%；经营预测 15.4%；现金流/估值桥 12.3%；基准保护 3.1%；情景比较 3.1% |

表中数值是总分占比，显示到一位小数，计算仍使用完整精度；[精确权重](https://github.com/alex051107/new6-judge-review-20260905/blob/main/results/unified-scores-v3/weights.csv)与[逐项判据](https://github.com/alex051107/new6-judge-review-20260905/blob/main/docs/JUDGE.md)保存在附件。这里的60/40是当前报告使用的配重，参考、等价实现和业务错误案例用于检查判据是否测到了对应义务；权重的合理性仍由这些证据和人工审查共同检验。

各项占比的小数来自按比例换算。例如A1的基准保护原占5%，所在组原合计65%；该组现占40%，于是这一项为40%×5÷65≈3.1%。小数位不表示经过同等精度的权重验证，合理性应由业务义务和核验案例支持。

核验案例要回答两个问题：保持业务含义但更换布局或公式，是否仍得到相应信用；明确遗漏或破坏某项业务关系，是否只在相关判据失分。已有参考和正反向校准为对应Judge版本提供了核验依据。各回执的版本和校准范围见附件，避免把一个版本的校准结果套到全部成绩上。

同一份A1真实答卷已实际重复评分5次，六项信用及总分的样本标准差均为0，低于0.05。[五次回执与一致性统计](https://github.com/alex051107/new6-judge-review-20260905/blob/main/results/unified-scores-v3/consistency.json)可复核；这项检查证明该答卷的重复评分一致，系统性读取问题仍需独立核对。

业务判分采用确定性程序，评分时未调用LLM Judge。数值、记录和明确业务关系都能与独立答案复算，再按相应条目计算信用。人工审查另行记录，不设第二套自动通过规则。

B1的位图图表使用已保存的视觉读数记录，按图片哈希绑定，再由程序核对标签和数值。其报告/图表一致性项占4.9%，其中图表占该项一半，即总分约2.5%；原生图表直接读取结构。视觉记录没有完整标注生成者或模型身份，需补充并供人审核对原图。其余任务不靠这份记录；本版不支持的图片会待判。

判分顺序是：读取候选工作簿，绑定对象、字段、期间和单位；与独立答案及业务关系核对；检查题目要求的更新、完整性与保护；形成逐项信用，最后按60/40汇总。Python、openpyxl及Excel内部结构负责读取，适用的公式更新由固定LibreOffice环境在原件隔离副本上重算。

未舍入分数达到0.70即通过，没有额外hurdle或隐藏封顶。合理表名、布局和等价单位不扣分；缺少题面明确要求的结果、比较图、解释或来源，按对应已有判据失分。必要事实尚无法判断时保留待判，不计零、不缩小分母。
